Explicación interactiva del código mdf_extractor.py — navega por secciones usando los botones

¿Qué hace este programa?
El script recibe un archivo de diccionario (.txt, .docx o .pdf), extrae automáticamente cada entrada léxica y la convierte a un formato estructurado (JSON, YAML o MDF).

Flujo principal del programa

1
Leer el archivo — según su extensión usa read_txt, read_docx o read_pdf para extraer el texto crudo.
2
Detectar el formato — detect_format() decide si el texto ya tiene etiquetas \tag o es texto plano sin estructura.
3
Parsear las entradas — usa parse_mdf_tagged() si ya tiene etiquetas, o parse_raw_dictionary() si es texto libre.
4
Serializar la salida — convierte las entradas al formato solicitado: to_json(), to_yaml() o to_mdf_text().
5
Escribir resultado — imprime en pantalla o guarda en un archivo, según lo que el usuario haya especificado.

Las bibliotecas se importan dentro de bloques try/except para que el programa funcione incluso si alguna no está instalada. Si falta una, la variable *_AVAILABLE queda en False y el error se lanza solo cuando se necesita esa funcionalidad.

Constantes globales
Definen la estructura que tendrá cada entrada del diccionario. Son la "columna vertebral" de todo el programa.
MDF_FIELDS = [
    "id", "lx", "ps", "sn", "se", "ph", "mr",
    "de", "dn", "ge", "gn",
    "xv", "xe", "xn", "rf",
    "cf", "lf", "lv", "wv", "vd",
    "nt", "et", "sc", "lo", "pc"
]

REPEATABLE = {"xv", "xe", "xn", "rf"}
¿Por qué REPEATABLE?
Los campos xv xe xn rf pueden aparecer múltiples veces en una misma entrada (varios ejemplos, varias fuentes). Por eso se almacenan como listas en lugar de cadenas de texto. Todos los demás campos son cadenas simples.
new_entry() — función auxiliar
Crea un diccionario vacío con todos los campos MDF. Los campos repetibles inician como lista [], los demás como cadena vacía "".
def new_entry():
    return {f: ([] if f in REPEATABLE else "") 
            for f in MDF_FIELDS}
Tres funciones de lectura
Cada función recibe una ruta de archivo y devuelve el contenido como texto plano. La función principal extract() elige cuál llamar según la extensión.
read_txt(fp)
La más simple. Abre el archivo con UTF-8 y lo lee completo. El parámetro errors='replace' evita que el programa falle con caracteres inusuales.
def read_txt(fp):
    with open(fp, 'r', encoding='utf-8', errors='replace') as f:
        return f.read()
read_docx(fp)
Usa python-docx para extraer texto de párrafos y celdas de tablas. Verifica primero que la biblioteca esté disponible.
def read_docx(fp):
    if not DOCX_AVAILABLE:
        raise ImportError("Instala: pip install python-docx")
    doc = docx.Document(fp)
    parts = [p.text for p in doc.paragraphs]
    for tbl in doc.tables:       # también extrae tablas
        for row in tbl.rows:
            for cell in row.cells:
                parts.append(cell.text)
    return "\n".join(parts)
read_pdf(fp)
Usa PyMuPDF (fitz) para abrir el PDF, extrae el texto de cada página y cierra el documento.
def read_pdf(fp):
    if not PDF_AVAILABLE:
        raise ImportError("Instala: pip install PyMuPDF")
    doc = fitz.open(fp)
    text = "".join(page.get_text() for page in doc)
    doc.close()
    return text
detect_format(text)
Analiza el texto para decidir qué parser usar. Busca con expresión regular cuántas etiquetas MDF comunes aparecen en el texto. Si hay 3 o más, asume que ya está etiquetado.
def detect_format(text):
    hits = len(re.findall(
        r'^\\(lx|ps|de|dn|xv|sn)\b', 
        text, 
        re.MULTILINE
    ))
    return "mdf_tagged" if hits >= 3 else "raw"
Texto MDF etiquetado
Contiene líneas como \lx ba, \ps n, \de egg. → se usa parse_mdf_tagged
Texto plano / sin etiquetas
Bloques separados por líneas en blanco, sin marcadores → se usa parse_raw_dictionary
parse_mdf_tagged(text) — el parser principal
Recorre el texto línea por línea. Cuando encuentra \lx abre una nueva entrada. Cuando encuentra otra etiqueta \tag valor la asigna al campo correspondiente.
for raw in text.splitlines():
    line = raw.rstrip()
    m = re.match(r'^\\(\w+)\s*(.*)', line)
    
    if m:
        tag, value = m.group(1).lower(), m.group(2).strip()

        if tag == "id":
            pending_id = value   # guarda el \id para asignarlo al \lx siguiente
            continue

        if tag == "lx":
            if current is not None:
                entries.append(current)  # guarda entrada anterior
            current = new_entry()
            current["lx"] = value
            if pending_id is not None:
                current["id"] = pending_id
                pending_id = None
            continue

        if tag in REPEATABLE:
            current[tag].append(value)   # agrega a lista
        elif tag in MDF_FIELDS:
            current[tag] = value         # asigna cadena
Detalle importante: pending_id
En los diccionarios, \id aparece antes que \lx. La variable pending_id "recuerda" el ID hasta que aparece el lexema y lo puede asignar correctamente.
Líneas de continuación
Si una línea no empieza con \tag pero tampoco está vacía, se considera continuación del campo anterior y se concatena con un espacio.
parse_raw_dictionary(text) — parser heurístico
Para diccionarios sin etiquetado. Divide el texto en bloques separados por líneas en blanco. Cada bloque es una posible entrada léxica.
1
La primera línea de cada bloque se toma como el lexema (\lx).
2
Si la segunda línea coincide con el patrón de parte del discurso (n., v., adj., etc.), se asigna a \ps.
3
Las líneas que coinciden con [\texto] se asignan a \ph (transcripción fonética).
4
Las líneas cortas con palabras en español (el, la, un, de, que) se asignan a \dn. Las demás a \de.
5
Las líneas largas (más de 30 caracteres) se clasifican como ejemplos (\xn o \xe) según el idioma detectado.
POS_RE = re.compile(
    r'^[\[\(]?(s\.|st\.|n\.|v\.?\d?|vt\.|vi\.|vp\.|'
    r'adj\.|adv\.|cont\.|prep\.|conj\.|pron\.?)[\]\)]?$',
    re.IGNORECASE
)
Limitación del parser heurístico
Al ser heurístico, puede cometer errores con texto poco estructurado. Para mejores resultados, se recomienda que los diccionarios ya tengan etiquetado MDF parcial, o que el texto tenga una estructura consistente.
Tres funciones de serialización
Convierten la lista de entradas (Python dicts) al formato de salida pedido. Primero pasan por entries_to_dicts() que garantiza que todos los campos estén presentes y con el tipo correcto.
entries_to_dicts(entries)
Normaliza cada entrada: recorre los campos en el orden definido por MDF_FIELDS, asegurándose que los campos repetibles sean listas y los demás cadenas de texto. Nunca produce None.
to_json(entries, indent=2)
Usa json.dumps() con ensure_ascii=False para preservar caracteres Unicode (tildes, caracteres IPA, etc.).
def to_json(entries, indent=2):
    return json.dumps(entries_to_dicts(entries), 
                      ensure_ascii=False, 
                      indent=indent)
to_yaml(entries)
Usa yaml.dump() con allow_unicode=True y sort_keys=False para mantener el orden de los campos MDF.
to_mdf_text(entries)
Produce la salida en formato \tag valor. Los campos repetibles generan múltiples líneas. Los campos vacíos producen \tag (con espacio) para mantener la estructura MDF completa.
Interfaz de línea de comandos (main)
Usa argparse para definir los argumentos que el usuario puede pasar al ejecutar el script.
parser.add_argument("input",          # argumento obligatorio
    help="Archivo de entrada (.txt, .docx, .pdf)")

parser.add_argument("--format", "-f", # opcional
    choices=["yaml", "json", "mdf"],
    default="json")

parser.add_argument("--output", "-o", # opcional
    help="Archivo de salida (por defecto: stdout)")

parser.add_argument("--indent",       # opcional
    type=int, default=2)
1
Verifica que el archivo exista con Path(args.input).exists(). Si no, imprime error y sale con código 1.
2
Llama a extract(args.input) que internamente lee el archivo y parsea las entradas.
3
Llama al serializador correcto según --format.
4
Si se especificó --output, escribe el resultado en ese archivo. Si no, lo imprime en pantalla (stdout).

Comandos de uso

Caso 1 — Archivo .txt a JSON (imprimir en pantalla)
python mdf_extractor.py diccionario.txt
Caso 2 — Archivo .txt a JSON, guardar archivo
python mdf_extractor.py diccionario.txt -f json -o salida.json
Caso 3 — Archivo .pdf a YAML
python mdf_extractor.py diccionario.pdf -f yaml -o salida.yaml
Caso 4 — Archivo .docx a formato MDF etiquetado
python mdf_extractor.py diccionario.docx -f mdf -o salida.mdf
